Google AI Studio API Key 발급 가이드

Gemini API를 사용하기 위한 API 키 생성 단계별 안내

1 API 키 생성 시작하기
  • Google AI Studio 대시보드에 접속합니다.
  • 우측 상단에 있는 🔑 API 키 만들기 버튼을 클릭합니다.
2 프로젝트 선택 및 키 발급
  • 새 키 만들기 팝업 창이 나타나면 키 이름 지정 입력란에 식별하기 좋은 이름을 입력합니다. (예: Gemini API Key)
  • 가져온 프로젝트 선택 드롭다운 메뉴를 클릭합니다.
  • 기존에 생성된 Google Cloud 프로젝트가 있다면 리스트에서 선택하거나, 새로 만들어야 할 경우 ➕ 프로젝트 만들기를 클릭하여 새 프로젝트를 생성합니다.
  • 연결이 완료되면 API 키가 발급됩니다.
