초보자용 API 가이드룸

API가 무엇이고 웹페이지에서 어떻게 가져다 쓰는지 눈으로 직접 확인해보세요!

1단계: API 데이터 만들기

API는 쉽게 말해 '데이터 메뉴판'입니다. 서버가 아래와 같은 형식(JSON)으로 데이터를 준비해 둡니다.

가상의 API 주소 (URL):

https://api.mysite.com/user/1

반환할 데이터 (JSON):

{
  "status": 200,
  "name": "김테스트",
  "job": "웹 개발자",
  "location": "서울"
}

2단계: 웹페이지에 연결하기

아래 버튼을 누르면 자바스크립트(`fetch`)가 위에 있는 API 메뉴판을 호출하여 화면에 그려줍니다.

버튼을 누르면 API 결과가 여기에 표시됩니다.
