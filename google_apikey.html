현재 화면 기준 API 키 가이드

지금 띄워두신 Google AI Studio 화면을 보며 순서대로 따라 해보세요!

클릭 1

우측 상단의 흰색 버튼 누르기

현재 화면의 오른쪽 윗부분을 보시면 흰색 배경의 [🔑 API 키 만들기] 버튼이 있습니다. 새로운 비밀번호 열쇠를 발급받기 위해 이 버튼을 눌러주세요.

API 키 만들기
버튼을 누른 후 대처법:
영어 팝업창이 뜨면 당황하지 마시고 맨 위에 있는 파란색 글씨인 "Create API key in new project" (새 프로젝트에 API 키 만들기)를 클릭해 주시면 됩니다.
클릭 2

생성된 키 복사(저장)하기

키가 정상적으로 만들어지면 현재 화면 중앙 목록(zeromeal 또는 openclaw 옆)에 추가됩니다. 목록 오른쪽에 있는 [복사 아이콘]을 누르면 컴퓨터에 글자가 자동으로 복사됩니다.
