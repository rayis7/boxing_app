내 화면 보며 API 키 만들기

지금 켜져 있는 Google AI Studio 화면에서 딱 두 가지만 기억하세요!

1단계

우측 상단의 흰색 버튼 누르기

지금 보고 계신 화면의 오른쪽 위를 보시면 아래와 같이 생긴 [API 키 만들기] 버튼이 있습니다. 망설이지 말고 클릭하세요!

API 키 만들기
팁: 버튼을 누르면 영어로 된 작은 창이 뜹니다. 당황하지 마시고 가장 첫 번째 파란 글씨인 "Create API key in new project" (새 프로젝트에 API 키 만들기)를 누르시면 3초 뒤에 완료됩니다!
2단계

생성된 열쇠(Key) 복사하기

키가 생성되면 화면 중간 목록에 아래와 같이 추가됩니다. 맨 오른쪽에 있는 [사각형 아이콘(복사)] 버튼을 누르면 컴퓨터에 자동으로 저장됩니다.
