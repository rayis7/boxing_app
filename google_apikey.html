🔑 Google API Key 발급 가이드

구글 지도, 유튜브, 번역 등 구글 서비스를 연동하기 위한 API 키 발급 절차입니다.

  • 1
    Google Cloud Console 접속 및 프로젝트 생성

    구글 클라우드 콘솔에 로그인한 뒤, 서비스를 이용할 프로젝트를 생성해야 합니다.

    • 오른쪽 상단의 [프로젝트 선택] -> [새 프로젝트]를 클릭합니다.
    • 프로젝트 이름을 입력하고 [만들기]를 누릅니다.
    구글 클라우드 콘솔 바로가기 ↗
  • 2
    사용할 라이브러리(API) 활성화

    내 프로젝트에서 어떤 구글 서비스(예: Maps, YouTube 등)를 쓸지 선택해야 합니다.

    • 왼쪽 메뉴(작대기 3개)에서 [API 및 서비스] > [라이브러리]로 이동합니다.
    • 사용하려는 API(예: YouTube Data API v3 등)를 검색합니다.
    • 해당 API를 클릭하고 [사용] 버튼을 누릅니다.
  • 3
    사용자 인증 정보 및 API Key 생성

    이제 실제로 웹페이지나 앱에 넣을 키를 발급받을 차례입니다.

    • 왼쪽 메뉴에서 [API 및 서비스] > [사용자 인증 정보]로 이동합니다.
    • 상단의 [+ 사용자 인증 정보 만들기] 버튼을 클릭합니다.
    • 드롭다운 메뉴에서 [API 키]를 선택하면 즉시 키가 생성됩니다!
  • 4
    보안을 위한 API 키 제한 (권장)

    발급받은 키를 다른 사람이 도용해 사용하면 요금이 청구될 수 있으므로 제한을 걸어두는 것이 안전합니다.

    • 생성된 API 키 옆의 수정(연필) 아이콘이나 [키 제한]을 클릭합니다.
    • 애플리케이션 제한: 웹사이트에서 쓸 경우 [웹사이트(HTTP 리퍼러)]를 선택하고 본인의 도메인을 등록합니다.
    • API 제한: 이 키가 특정 API(예: YouTube API)에만 작동하도록 묶어둡니다.
⚠️ 보안 주의사항 (중요!)

발급받은 API 키는 일종의 비밀번호입니다. GitHub 같은 공개 저장소에 소스 코드를 올릴 때 키가 그대로 노출되지 않도록 주의하세요. 만약 노출되었다면 즉시 해당 키를 삭제(삭제/해제)하고 재발급받으셔야 합니다.
